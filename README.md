# intestinal-mucus-particle-tracking
Analysis code for particle tracking of 100 nm PEGylated nanoparticles in murine colonic and ileal mucus as a function of depth, including measurements in intact and partially shaved mucus. The repository also includes tracking data for the same nanoparticles in mucus produced in vitro by HT29-MTX-E12 (human cell-derived mucus).
